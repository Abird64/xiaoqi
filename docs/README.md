## 三条铁律

1. **只信文件**。口头说定、群里聊定的事都不算数，**落进本目录才算数**。别人问「说好的吗」，答案永远是一个文件链接。
2. **只有一个进度真相源**。任务状态只看 [03-进度/看板.md](03-进度/看板.md)，任何人不得在其他地方另记一份待办。
3. **接口先冻结，再分头写代码**。三个人并行开发的前提是 [接口协议.md](02-需求与设计/接口协议.md) 已冻结；接口没定就写实现，等于返工。

## 术语速查

| 词 | 含义 |
|---|---|
| **owner（主责）** | 这模块出问题找他，改动前要知会他 |
| **备份人** | owner 失联/忙不过来时能顶上的人（每域必须有 1 人） |
| **XQ-xxx** | 任务卡编号，看板与提交信息、PR 描述里复用 |
| **M1–M4** | 里程碑，见 [01-规划/路线图.md](01-规划/路线图.md) |
| **冻结** | 该产物定版，改动必须走「只增不改 + 决策记录」 |
