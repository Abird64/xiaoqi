# 决策记录模板

> 决策记录**不单独建文件**，直接追加到 [01-规划/风险与决策.md](../01-规划/风险与决策.md) 的「二、决策记录」小节末尾。
> 复制下面这段贴过去，并把编号 +1。

---

```markdown
### D-00x 决策标题（YYYY-MM-DD）

- **背景**：为什么要做这个决定（不写心路历程，只写事实）
- **选项**：
  - A：〈做法〉—— 代价：〈代价〉
  - B：〈做法〉—— 代价：〈代价〉
  - C：不做 / 延后 —— 代价：〈代价〉
- **决定**：选 〈X〉
- **理由**：一句话，能说服三个月后的自己
- **影响**：谁要跟着改什么（具体到模块 / 卡号）
- **可逆性**：可逆 / 不可逆（**不可逆的必须三人一致同意**）
- **参与人**：〈谁在场〉
```

---

## 什么时候必须写

| 要写 | 不用写 |
|---|---|
| 影响范围（加/砍功能） | 用哪个库、函数怎么命名 |
| 接口冻结与变更 | 代码风格 |
| 技术栈变更（如 3D → 2.5D） | 临时的调试改动 |
| 里程碑时间调整 | — |
| 紧急救火（事后 24h 内补写） | — |

## 反悔怎么办

不是"删掉重写"，而是**追加一条新决策**并注明「取代 D-00x」。

```
### D-007 用 2.5D 替代 3D 渲染（2026-11-10）
- **背景**：D-006 的触发条件已满足（W10 结束时帧率 < 20）
...
- **取代**：D-006
```

> 保留历史决策的价值：三个月后能回答"我们当时为什么这么做"——答辩时这个最有用。
