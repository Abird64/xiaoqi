# 进度目录说明

| 文件 / 目录 | 是什么 | 谁写 |
|---|---|---|
| [看板.md](看板.md) | **唯一任务真相源**，所有人随时可改自己那几行 | 全员 |
| `周报/` | 每周一份 `YYYY-Www.md`（如 `2026-W38.md`） | 轮值主持汇总 |
| `会议记录/` | 每次会议一份 `YYYY-MM-DD-主题.md` | 轮值主持（会后 24h 内） |

---

## 周报写什么（4 段，超过一页就是写多了）

1. **本周完成**：对着看板抄 ✅ 的卡，每条带证据链接
2. **本周卡住**：卡在哪、需要谁、什么时候能解
3. **下周计划**：每人领的卡 ID
4. **投入与士气**：每人本周实际小时数 + 一句话状态（"还行 / 有点赶 / 快撑不住"）

> 第 4 段不是形式主义：连续两周低于 4 小时就要重排分工，这是**提前发现掉队**的唯一办法。

---

## 会议记录写什么（只记三样）

- **结论**（决定了什么）
- **谁做什么**（行动项 + 期限）
- **什么时候**（截止时间）

过程讨论、谁说了什么、谁反对什么——**不用记**。

---

## 命名规则

| 类型 | 文件名 | 例子 |
|---|---|---|
| 周报 | `YYYY-Www.md`（ISO 周号） | `2026-W38.md` |
| 会议 | `YYYY-MM-DD-主题.md` | `2026-09-16-周会.md` |
| 决策 | 写进 `01-规划/风险与决策.md`，**不单独建文件** | `D-004 ...` |
