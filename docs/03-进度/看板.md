## 卡片命名与粒度规则

| 规则 | 说明 |
|---|---|
| 一张卡 = 一个可验收结果 | 验收标准写不出来 → 说明还没想清楚，先别开工 |
| 预估时长 0.5–4 小时 | 超过 4 小时 → 拆成两张 |
| 一张卡只动一个模块 | 跨模块的卡拆开，或明确标注为「联调卡」 |
| 编号顺序 | 编号是**非空**的：W1–W13 见 [系统架构](../02-需求与设计/系统架构.md) |
| ID 不复用 | 卡片取消就标 ⛔ 并写原因，不要删行（便于追责与复盘） |

## 每周维护动作（轮值主持）

1. 周一开会前：扫一遍所有卡，把上周实际完成的改成 ✅（**带上证据链接**）。
2. 开会中：过一遍阻塞区，逐条给出解法或转给人。
3. 会后：新建下周的卡，当场填 owner 与期限；没有 owner 的卡不许留在表里。
