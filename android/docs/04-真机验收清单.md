## 1. 安装与首次启动

- [ ] `adb install -r release/xiaoqi-steps-1.0.0.apk` 成功（或文件管理器安装成功）。
- [ ] 桌面出现「小栖步数」图标；点击可打开。
- [ ] 首次打开出现「还差一步：允许身体活动」横幅。
- [ ] 点「授予权限」→ 系统弹出「身体活动」权限 → 允许。
- [ ] Android 13+ 同时弹出通知权限；允许后通知栏出现「小栖 · 今日 0 步」常驻通知。
- [ ] 首页状态胶囊变为「计步中」（或未启动，若服务尚未启动）。
- [ ] 点「启动计步」后，通知出现，状态为「计步中」。

**异常记录**：崩溃 / 白屏 / 权限循环 / 通知不出现。

---

## 2. 配置与连接

- [ ] 设置页地址输入 `http://<电脑IP>:8000`（或 8765）。
- [ ] 令牌输入正确；或点「自动获取令牌」成功填入。
- [ ] 点「测试连接」显示「已连接 · 小栖后端 x.y.z · 在线前端 N 个」。
- [ ] 若服务端已有手机步数，显示「服务端已有 X 步」。
- [ ] 点「保存并启动」提示「已保存，后台计步已启动」。
- [ ] 首页「同步到小栖」卡片显示电脑地址、上次同步、同步结果。

**错误路径**：

- [ ] 填错令牌 → 测试连接仍可通（health 不鉴权），但「立即同步」显示「令牌错误（HTTP 401）」。
- [ ] 填错 IP/端口 → 显示「连不上电脑 / 超时」，App 不崩溃。
- [ ] 地址填 `192.168.1.5:8000`（不带 http://）→ 保存后自动补全并可连接。
- [ ] 粘贴 `http://IP:8000/api/ingest/health` → 自动归一化为根地址。

---

## 3. 计步

- [ ] 关闭 App（或退到后台），走 100 步，再打开 App，数字增加约 100。
- [ ] 锁屏走 100 步，解锁打开 App，数字继续增加。
- [ ] 点「立即同步」，后端 `/api/state` 的 `phone.steps` 与 App 一致。
- [ ] 连续走 300+ 步，观察 75 秒后是否自动同步（看 `last_sync_at` / 通知）。
- [ ] 原地摇手机不应大幅增加（硬件计步器的正常过滤）。
- [ ] 系统健康 App 的今日步数与 App 的差值可解释（首次安装从 0 起算 / 断流丢弃）。

**异常记录**：步数倒退、暴增、长时间不涨、重启后归零错误。

---

## 4. 后台与重启

- [ ] 锁屏 10 分钟，期间走 50 步；解锁后数字增加，通知仍在。
- [ ] 从最近任务划掉 App；走 50 步，重新打开，数字仍增加（前台服务/Job 生效）。
- [ ] 重启手机（不打开 App）；走 50 步，再打开 App，数字增加，服务恢复。
- [ ] 关闭「开机自启」后重启，服务不自动启动；打开 App 后恢复（符合预期）。
- [ ] 在设置里「停止后台计步」，通知消失，锁屏不再计步；已记录步数保留。
- [ ] 重新「保存并启动」，恢复计步。

**厂商专项**：

- [ ] 小米/红米：允许「自启动」+「后台弹出界面」/「省电策略 无限制」。
- [ ] 华为/荣耀：应用启动管理 → 手动管理 → 允许自启动/关联启动/后台活动。
- [ ] OPPO/vivo：允许自启动 + 后台运行 + 电池不优化。
- [ ] 三星：电池 → 未监视的应用 / 允许后台活动。

---

## 5. 跨零点与日期

- [ ] 把手机时间调到 23:59，走 20 步，等待跨到 00:00，再走 10 步：
      App 今日步数应在零点归零，随后增加约 10（允许跨零点几秒的误差）。
- [ ] 或用设置页「今日清零」模拟：清零后数字为 0，再走 10 步变 10。
- [ ] 跨零点后第一次同步，后端 `steps` 变小，服务端应视为新的一天（参考后端行为）。
- [ ] 改回正确时间后，日切以手机当前本地日期为准。

---

## 6. 同步与错误恢复

- [ ] 关闭电脑 Wi-Fi / 停后端；点「立即同步」→ 显示同步失败，App 不 ANR/不崩溃。
- [ ] 恢复后端；等待一个同步周期或点「立即同步」→ 成功，状态变「已同步」。
- [ ] 60 秒内连点两次「立即同步」→ 第二次可能提示「已同步（服务端 60 秒内去重）」。
- [ ] 超过 15 分钟不打开 App / 不同步，前端步数卡显示「待同步」。
- [ ] 后端重启后令牌变化 → App 显示 401；重新「自动获取令牌」/填新令牌后成功。
- [ ] 飞行模式走步 → 恢复网络后自动补报（下一次周期）。

## 7. 界面与可访问性

- [ ] 小屏（5.0" / 720p）首页无需横向滚动，按钮不被遮挡。
- [ ] 大字体/显示大小调大后，卡片文字不重叠、按钮仍可点。
- [ ] 深色模式下配色正常（App 固定深色，不跟随系统反色）。
- [ ] 横屏/旋转后数据不丢、服务不断。
- [ ] TalkBack 能读出「今日 N 步，目标 M 步」、按钮名称、同步状态。
- [ ] 通知点击进入 App；通知「立即同步」可用；「设置」可用。
- [ ] 电池优化设置入口可打开（不同 ROM 可能跳到列表页）。

## 9. 通过标准

- 第 1–6 节全部勾选；无崩溃、无 ANR、无数据倒退/暴增；
- 锁屏/重启后仍能计步；
- 断网→恢复后能自动补报；
- 前端步数卡/挂历显示与后端 `phone.steps` 一致；
- 已知限制（首次安装从 0、跨天断流丢弃、调试签名/明文 HTTP）被记录并接受。
